# Bronze Layer: AWS Glue Crawler & Schema Discovery

## Overview
The **Bronze Layer** represents the raw ingestion layer of the ChurnLens pipeline. Instead of executing manual `CREATE EXTERNAL TABLE` DDL queries, **AWS Glue Crawler** was utilized to automatically scan raw CSV files stored in Amazon S3, infer data schemas, and register the metadata into the **AWS Glue Data Catalog**.

---

## Step-by-Step Configuration

1. **Storage Setup (S3):**
   - Raw customer churn datasets in CSV format were uploaded to the primary landing bucket:
     `s3://churn-s3-bronze/bronze/`

2. **Crawler Setup (AWS Glue):**
   - **Crawler Name:** `churn-bronze-crawler`
   - **Data Source:** Amazon S3 (`s3://churn-s3-bronze/Customer_Data.csv/`)
   - **IAM Role:** Attached IAM Role with `AWSGlueServiceRole` and read access to the target S3 bucket.
   - **Output Database:** `customer_churn_db`
   - **Table Created:** `churn_s3_bronze`, `gold_v_customer_churn`, `silver_customer_clean`

3. **Execution & Schema Inference:**
   - The crawler scanned the raw headers and data rows, automatically detecting column names and mapping data types (Strings, Integers, Doubles).

---

## Inferred Schema Definition (DDL Equivalent)

Below is the conceptual DDL representing the schema automatically generated by AWS Glue in Athena:

```sql
CREATE EXTERNAL TABLE IF NOT EXISTS customer_churn_db.churn_s3_bronze (
    customer_id STRING,
    gender STRING,
    senior_citizen INT,
    partner STRING,
    dependents STRING,
    tenure INT,
    phone_service STRING,
    multiple_lines STRING,
    internet_service STRING,
    online_security STRING,
    online_backup STRING,
    device_protection STRING,
    tech_support STRING,
    streaming_tv STRING,
    streaming_movies STRING,
    contract STRING,
    paperless_billing STRING,
    payment_method STRING,
    monthly_charges DOUBLE,
    total_charges DOUBLE,
    churn STRING,
    state STRING
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION 's3://churn-s3-bronze/bronze/'
TBLPROPERTIES ('skip.header.line.count'='1');
